# 数字人换背景 / 抠像说明

数字人的画面来自形象素材（`data/avatars/<id>/full_imgs`）和动作素材
（`.../gestures/<动作>/full_imgs`）。换背景分两步：**先抠像**，再**选背景**。

## 一、抠像（每换个形象做一次）

```bash
# 抠全部帧（默认素材 + 所有动作），并生成一张三种背景的对比预览图
python scripts/avatar_matte.py --avatar musetalk_ke --preview docs/matte-preview.png

# 只抠默认素材（动作还没做好时先看效果）
python scripts/avatar_matte.py --avatar musetalk_ke --frames base

# 素材更新后强制重算
python scripts/avatar_matte.py --avatar musetalk_ke --force
```

产出：

```
data/avatars/<id>/matte/manifest.json
data/avatars/<id>/matte/base/00000000.png            # alpha，255=人 0=背景
data/avatars/<id>/matte/gestures/<动作>/00000000.png
```

脚本自带两套算法：默认 `chroma`（面向纯色/浅色影棚底，零依赖）和 `rembg`
（装了 rembg 才可用）。边缘参数：`--lo`（背景判定，越大越严）、`--hi`（过渡带，
越大边缘越软）。

### 算法怎么处理这几类难缠的地方

`chroma` 不是简单的"接近白色就透明"，它按五步走，每一步对应一类真实问题：

| 步骤 | 解决什么 | 判据 |
| --- | --- | --- |
| 背景连通域 | 被西装包住的白衬衫 | 只有**与画面四边连通**的白才算背景 |
| 闭运算 + 填洞 | 西装内部的深色阴影、扣子 | 被前景围住的小块 |
| 细缝识别 | 手臂与躯干之间、手指缝、大腿根部 | 很细（内切半径 ≤4.5px）+ 离轮廓 9~60px |
| 去溢色（合成时） | 人像边缘一圈白边 | 按 `I = a·F + (1-a)·B` 反解前景色 |
| 地面阴影抑制 | 鞋底那圈白光 | 画面下部 + 低饱和 + 偏亮 |

**细缝识别**是重点：这类缝两三个像素宽，既不跟画面四边连通（不算背景）、又细到
不构成"内部空洞"，闭运算会直接把它填进人体，换到深色背景上就是一道白光。判据靠
三个距离：

- 太贴轮廓（<9px）→ 是袖口、衣领这类真衣物，保留；
- 陷得太深（>60px）→ 是领带斜纹这类**衣物花纹**，保留；
- 中间地带（9~60px，臂缝 45px、指缝十几像素）→ 是缝，挖掉。

**暖白 vs 中性白**：指甲盖、指节高光是「暖白」（R 比 B 高 15 以上），影棚白底是
「中性白」（R≈B）。所有"清白色/往外扩"的规则都加了 `neutral_white` 限制，否则
指甲会被啃掉、拇指末端缺一块。

**饱和度红线**：皮肤 55~80、深色西装 110~150、白衣与白底 <15。凡是要"清浅色"的
判断，`sat` 阈值必须压在 35 以下，否则一定啃到皮肤（手会破洞、拇指像被切）。

**去溢色**在合成阶段做，用 manifest 里记录的原始背景色 `bg_color` 反解真实前景色，
否则边缘的"白底+人像"混合像素会在线性叠加时露出白边。换形象后重跑脚本会自动
更新这个值。

## 二、选背景

桌面版：**开播页 → 画面背景**，下拉里可选「原背景 / 内置纯色 / 已上传图片」，
点「上传图片」可以加自己的图（png/jpg/webp/bmp，≤20MB）。**换完重新连接生效。**

内置背景图（`data/backgrounds/`，下拉里显示中文名）：

| 文件 | 显示名 | 适合场景 |
| --- | --- | --- |
| `training_stage.png` | 环形实训台 | 科技感最强，人正好站在发光地台上 |
| `training_medical.png` | 医疗实训室走廊 | 医疗/护理类课程 |
| `training_dome.png` | 科技环形大厅 | 发布会式的开场 |
| `training_classroom.png` | 明亮实训室 | 常规授课，最自然 |

接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/avatar/background` | 当前配置 + 可用背景 + 是否已抠像 |
| PUT | `/api/avatar/background` | `{"type":"none\|color\|image","value":"#101F33\|data/backgrounds/x.jpg"}` |
| POST | `/api/avatar/background/upload` | multipart 字段名 `file` |
| GET | `/api/avatar/background/preview` | 返回当前配置下的合成预览 JPG |

配置落在 `data/settings/background.json`，背景图落在 `data/backgrounds/`。

## 三、实现位置

- 抠像：`scripts/avatar_matte.py`
- 运行时合成：`utils/avatar_background.py`（背景按 cover 铺满、alpha 按帧源+帧号取、
  边缘去溢色）
- 接入点：`avatars/base_avatar.py` 的 `_frame_at()` / `_base_frame_at()`
  —— 取帧这一层合成，推理贴脸、动作切换、暂停帧都会自动带上新背景，
  没配背景时这段只多一次 `None` 判断，不影响帧率。

## 四、换形象 / 调参数时

```bash
# 换形象后：先抠像，再在开播页选背景（重新连接生效）
python scripts/avatar_matte.py --avatar <新形象ID> --preview docs/matte-preview.png
```

如果发现某处不该透（比如衣物花纹被挖），把 `--lo` 调小一点会更保守；如果缝没挖
干净，检查该缝到轮廓的距离是否落进 9~60px 这个区间（`_thin_background_gaps` 的
`min_inset` / `max_inset`）。
