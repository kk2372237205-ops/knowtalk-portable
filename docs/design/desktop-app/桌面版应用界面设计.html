桌面版设计规格（供 desktop_app.py 实现对齐）

配色令牌
主背景 #FBF8F1
面板 / 卡片 #FFFDF8
边框 #E6E1D2 / #D8CFB8
墨色·主按钮 #12253D
强调绿·状态 #1D6B4A
次要文字 #968F80
警示 / 断开 #83302A
字体与字号
19知课 KnowTalking（顶栏 / 标题）
14-15面板标题、页签
13正文、表单、导航
12辅助说明、状态、SID
11页脚提示、暂无标签
字体：系统无衬线栈（微软雅黑 UI / PingFang SC），不引入网络字体；SID、字数等数据用等宽 Consolas。
网页 → 桌面映射
浏览器导航 / 页面跳转→应用顶栏常驻 + 视图切换
首页「进入工作台」→登录后直接进入工作台
工作台左侧功能导航→侧栏页签（开播 / 讲稿 / 提问…）
开播实况面板→右侧常驻面板，连上即刷新
展示页（浏览器新页）→独立窗口 / 视图，顶栏可返回
状态、SID→顶栏常驻，切页不丢
组件规范：主按钮 = 墨色底 #12253D、6px 圆角、14px 字号；输入框 / 下拉 = 白底 #FFFDF8、1px #D8CFB8 边框、聚焦变墨色；状态点 8px 圆点（灰=未连接，绿=已连接，红=异常）；侧栏激活项 = 米白底 + 左缘 3px 绿色条。窗口尺寸建议 1280×800（工作台 1440×860 起步）。
