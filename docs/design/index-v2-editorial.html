In class

题目挂在哪一页，
就等到哪一页。

讲稿里写 [QUIZ:3]，讲到第 3 页就停下、静音、把幻灯片冻住，等人作答。翻页之前它就这么等着，不催你，也不会自己跳过去。

  • Trigger讲到那一页才触发按页序比较，不认页码数字大小
  • Grade模型判分，写明依据判分在后台线程跑，不冻住视频
  • Record作答和成绩存在本机「继续播放」不计为未作答
