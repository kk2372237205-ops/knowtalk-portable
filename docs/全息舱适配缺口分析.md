## 二、P0 —— 不做就跑不起来

### 1. 1050Ti 4GB 显存：MuseTalk 能否跑得住（先验证，再谈别的）
当前数字人是 MuseTalk，服务端日志显示 VAE 解码约 42ms/帧、`batch_size=8`、输出 20fps，
本机（显存 8G 级）才勉强跑顺。1050Ti 只有 4GB：
- 必须实测：降 `batch_size`（8→2/4）、降 `modelres`、开 fp16；
- 跑不动就切轻量方案（项目里已有 `ultralight` 分支，或 wav2lip 类模型）；
- 建议直接在规格书提到的 **OPS 主机上换一张 8G 以上显卡**，成本最低。

### 2. 8GB 内存：主服务加载 torch + MuseTalk 需要 4GB 以上空闲
本机排查经验：可用内存低于 2.5GB 时主服务必然启动失败（报 WinError 1114/1455，
界面上常被误显示成"显存不足"）。8GB 内存的机器上，系统 + 舱体控制软件 + 主服务
几乎没有余量。**建议内存升到 16GB**，否则会频繁出现"开不了机"。

### 3. 竖屏 9:16 布局
当前桌面版是 1360×860 的**横屏布局**（左侧 212px 导航 + 右侧宽内容区）。
全息舱是竖向大屏，横屏布局放上去会出现大片空白和数字人过小：
- 导航应改为**底部横向标签栏或顶部窄条**，主体留给数字人画面；
- 数字人画面按竖屏比例铺满（现在的输出已经是竖屏比例，方向对）；
- 页面内容区改为单列纵向排布。

### 4. 4K 高 DPI 适配
已有 `UI_SCALE`（按系统 DPI 换算）+ `S()` 缩放函数，但需在真实的 2160×3840
下实测字号、按钮高度、间距，避免字过小或控件溢出。

## 三、P1 —— 功能缺口（对照云端平台手册）

| # | 平台已有功能 | 桌面版现状 | 缺口说明 |
|---|---|---|---|
| 5 | **唤醒词库 / 打断词**（含词条增删改） | 无 | 全息舱是语音交互，没有唤醒词就只能一直手动触发；打断词用于控制"说话中被打断" |
| 6 | **菜单库**（菜单项 + 预置问题 / 跳转链接，端侧展示按钮） | 无 | 舱体屏幕需要可点击的菜单按钮 |
| 7 | **商品库**（商品名称 / 价格 / 图片 / 商品码，支持链接导入解析） | 无 | 展项导购场景常用 |
| 8 | **问答库**（关键词精确匹配 + 预生成状态 + 显示素材） | 只有 RAG 语义检索（课程知识库）+ 提问模式 | 缺关键词精确匹配问答，缺"答案里带图片/视频素材" |
| 9 | **闲时视频 / 待机提示**（可设数字人闲时视频） | 待机是静音帧 + 画布提示文字 | 舱体截图上写着"您可以站在我的前方进行语音交流"，说明有**待机引导态**，桌面版没有可配置的待机视频/引导语 |
| 10 | **设备管理**（设备列表、编辑互动类型、下发配置） | 无（单机本地配置） | 多台舱需要设备标识 + 远程拉取配置 |
| 11 | **4 阵列定向麦克风 / 音频输出设备选择** | 用 sounddevice 默认设备 | 需指定阵列麦克风为输入设备；扬声器 2×15W，**必须做回声消除（AEC）**，否则数字人说话会被自己拾音 |
| 12 | **摄像头 500 万像素** | 未使用 | 可做人体接近检测 → 自动进入迎宾态 |
| 13 | **素材展示区**（回答时展示图片/视频） | 无 | 与 #8 联动 |
| 14 | **问答记录**（按是否匹配查询） | 无 | 运营复盘用 |

## 四、P2 —— 展项化需要（非功能，但决定能不能交付）

- **开机自启 + 无人值守**：展项设备要能上电即播，桌面版目前手动双击启动。
- **看门狗 / 自动恢复**：主服务崩溃、WebRTC 断流后自动重连重播。
- **服务健康检查与告警**：本机已有 `/api/status`（CPU/内存/显存），可加一个"异常自动重启"。
- **防误触 / 隐藏鼠标**：舱体无键鼠，界面不该出现需要键盘输入的地方。

---

## 五、建议实施顺序

1. **先跑通再说功能**：拿 OPS 主机（或临时插一张 8G 显卡 + 加到 16G 内存）实测
   MuseTalk 在 4GB 显存下的可行性，定下最终模型方案和帧率。
2. **竖屏布局改造**：导航移到顶部/底部，数字人画面铺满，页面单列化。
3. **语音链路**：指定 4 阵列麦克风 → AEC 回声消除 → 唤醒词 → VAD → 打断。
4. **待机态**：待机视频 / 引导语 + 摄像头接近唤醒。
5. **内容层**：菜单库 → 问答库（关键词 + 素材）→ 商品库。
6. **展项化**：开机自启、看门狗、健康上报。

---

## 六、最容易踩的坑

- 规格书里 **4K(3840×2160) 与 9:16 自相矛盾**，动手改布局前一定先拿真机量一次实际分辨率。
- 别被"显存不足"的提示骗了：本机排查下来 1114/1455 的真实原因基本都是**系统内存不足**。
- 舱体扬声器 30W，回声消除不做的话语音识别会一直被自己干扰。
