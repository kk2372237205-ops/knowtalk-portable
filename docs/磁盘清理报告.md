## 三、后续如需执行（供参考，未执行）

清理缓存建议用系统自带「存储感知」或磁盘清理，比手动删除更安全：

1. **设置 → 系统 → 存储 → 临时文件** → 勾选后点「删除文件」
   （可处理 Windows 更新缓存、临时文件、传递优化、缩略图等）
2. **conda 缓存**：`conda clean -a`（需先退出所有 conda 环境）
3. **pip 缓存**：`pip cache purge`
4. **NVIDIA / JetBrains 缓存**：关闭相关软件后手动删除对应文件夹
