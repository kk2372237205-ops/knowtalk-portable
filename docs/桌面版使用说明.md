# 知课 KnowTalking - Tkinter 原生桌面版使用说明

本版本是**不依赖任何浏览器/WebView 内核**的原生 Windows 应用：

- 界面：Tkinter 原生窗口（登录 → 工作台，四个页签：数字人 / 聊天 / 音色与设置 / 系统状态）
- 数字人音视频：aiortc 原生 WebRTC 接收端（音频 → sounddevice 播放，视频 → 窗口内逐帧显示）
- 语音输入：麦克风录音 → 本地 whisper 转写
- 后台主服务：仍由原版 app.py 提供（本机 localhost 通信，与浏览器无关）

## 一、启动

双击 `start_app.bat`，或：

```
C:\Users\24306\.conda\envs\livetalking\python.exe desktop_app.py
```

首次启动会自动拉起主服务（模型加载约 1-2 分钟，期间窗口状态栏显示"正在启动主服务…"）。
若主服务已在运行（比如你自己用命令行启动了 app.py），桌面版直接复用，不会重复启动。

## 二、页面功能

| 页签 | 功能 |
| --- | --- |
| 数字人 | 连接/断开数字人（WebRTC 原生接收）、播放暂停、打断朗读、视频实时显示 |
| 聊天 | 发送聊天（LLM 回复由数字人朗读）、讲稿朗读（支持 [PPT:N] 标签）、语音输入（麦克风→转写→发送）、打断 |
| 音色与设置 | TTS 引擎（edgetts/sapi/xtts/fishtts…）、备用引擎、语速、参考音色下拉（系统音色+已上传克隆音色）、参考文本、数字人形象、上传克隆音色、本地 TTS 服务选择 |
| 系统状态 | RAG/LLM/会话数、重启主服务 |

## 三、音色与本地 TTS

- 「本地 TTS 服务」三选一：
  - **XTTS-v2**（默认）→ 主服务自动带 `--TTS_SERVER http://127.0.0.1:50000`
  - **Fish Speech** → `--TTS_SERVER http://127.0.0.1:50001`
  - 不使用本地 TTS → 走在线/系统音色
- 切换后点「应用（重启主服务）」，再到「系统状态」页点「重启主服务」生效。
- 参考音色下拉会加载系统音色（Edge 神经语音 + Windows SAPI 语音）与已上传的克隆音色；
  选系统音色时引擎选 edgetts/sapi，选克隆 wav 时引擎选 xtts/fishtts。
- 保存设置后**新建的会话**生效（「数字人」页重新连接即可）。

## 四、注意（重要）

1. **显存/内存**：主服务 MuseTalk 加载需要较多显存（约 3GB+）。
   若你同时常驻 RAG 服务、XTTS、Fish 等多个模型服务，可能导致主服务启动时被系统终止
   （窗口会提示"主服务进程已退出/启动超时"，日志在 `logs\desktop_server.log`）。
   此时请先关闭部分常驻服务（例如先停 XTTS 或 Fish 服务），再重启桌面版。
2. **首次登录**：系统无账号时会显示"创建管理员账号"表单，创建后进入工作台。
3. **退出**：关闭窗口会断开数字人连接、停止由桌面版启动的主服务（你自己启动的服务不受影响）。
4. 网页版（web/）与旧 pywebview 套壳（desktop.py / start.bat）已移除，项目仅保留本桌面版。

## 六、显存优化（2026-10-29 已生效）

为把 MuseTalk 显存压到最低，主服务做了以下调整（全部可回退）：

| 优化项 | 修改 | 效果 |
| --- | --- | --- |
| 推理批次 | `batch_size` 默认 16 → **8**（config.py） | UNet/VAE 推理激活峰值减半 |
| 预热批次 | warm_up 用 `min(batch_size, 2)`（app.py 三处） | 启动期峰值最低 |
| 显存分配器 | `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True,garbage_collection_threshold:0.6`（app.py 顶部） | 减少碎片、及时回收 |
| 加载后回收 | 模型加载完成后 `torch.cuda.empty_cache()` + `gc.collect()` | 释放加载期缓存 |
| numpy 兼容 | 注册 `numpy._core` → `numpy.core` alias（app.py） | 修复 avatar 素材 pickle（numpy 2.x 序列化）读取 |

**实测**：显存占用 XTTS + 主服务 + 系统合计约 5.3GB / 8GB，主服务常驻增量约 **1.8GB**；
优化前（batch=16 无分配器优化）加载期会顶满 8G 卡直接崩溃。
若仍紧张，可再停一个常驻 TTS 服务（Fish 50002/50001 或 XTTS 50000 二选一保留）。
