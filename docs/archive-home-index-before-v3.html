核心能力

一台机器，装下整间微课教室

从形象生成到课堂互动，常用能力全部内置，不必在多个工具之间来回切换。

形象与声音

三种口型驱动模型自由切换，上传一段参考音频即可克隆音色，每个形象独立保存参数。

  • wav2lip / musetalk / ultralight 一键切换
  • 声音克隆：上传参考音频即刻可用
  • 口型幅度、手势预设按形象微调

课件与讲稿

PPT 自动转图分页，[PPT:N] 标签驱动翻页，讲稿中可即插即用手势与提问点。

  • [PPT:N] 标签讲到哪页翻到哪页
  • 预设文本库：保存、复用、删除
  • 手势标签插入讲稿，播一遍就停

课堂互动

讲到提问点自动停下等学员作答，支持题库抽题与 LLM 判分，知识库回答带引用溯源。

  • 按页码触发提问，无限期等待作答
  • LLM 判分，成绩自动记录
  • RAG 检索增强，回答带课程引用
