# 声音克隆使用说明

上传一段人声，数字人就能用这个人的音色朗读讲稿。

## 一、怎么用（三步）

1. **素材与设置 → 声音克隆 → 启动服务**
   第一次用会提示下载模型（XTTS-v2，约 1.9GB），下载完再点一次「启动服务」。
   状态灯变绿、显示「就绪（cuda）」就可以用了。

2. **选择音频并克隆**
   挑一段 **3~10 秒**的干净人声（不要背景音乐、不要多人说话）。
   克隆完会出现在下面的音色列表里，可以点「试听」先听效果。

3. **让数字人用它说话**
   在「高级设置」里把 **TTS 引擎选成 `xtts`**，**参考音色选列表里的名字**，
   保存后重新连接数字人。之后所有讲稿都会用这个音色朗读。

> 音频会被统一转成 24kHz 单声道 wav 存在 `data/voices/`，
> 格式不支持时（比如某些 m4a/webm）会提示「读不了这个音频，建议先转成 wav」。

## 二、技术方案

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 引擎 | **XTTS-v2**（Coqui TTS 0.22） | 零样本克隆（不用训练）、中文开箱可用、显存约 2~3GB |
| 部署 | 独立进程 `scripts/voice_clone_server.py`，端口 50000 | 不用克隆时不启动，不跟数字人抢显存 |
| 客户端 | 复用已有的 `tts/xtts.py` | 协议对上即可，主服务不用改 |

**为什么不是别的方案**：GPT-SoVITS / CosyVoice 中文效果也很好，但都要另起一套
Python 环境和更大的模型；而本机 conda 环境里已经装着 `TTS==0.22.0`（XTTS），
能直接跑起来，少装一套东西就少一处版本冲突。

## 三、接口

桌面端只跟主服务通信，克隆服务由主服务代理（`/api/clone/*`）：

| 接口 | 作用 |
| --- | --- |
| `GET /api/clone/status` | 服务是否就绪（含 device、loading、error） |
| `POST /api/clone/speaker` | multipart 上传音频 → 返回 `speaker_id` |
| `GET /api/clone/speakers` | 已克隆音色列表 |
| `POST /api/clone/preview` | 合成一句试听（返回 wav，带文件头可直接播放） |
| `DELETE /api/clone/speaker/{sid}` | 删除音色 |

克隆服务自身的接口（主服务内部用）：`/health`、`/clone_speaker`、
`/tts_stream`、`/preview`、`/speakers`。

## 四、踩过的坑（改动代码前先看这里）

1. **torch.load 默认 `weights_only=True`**
   torch 2.6+ 之后加载 XTTS 的 checkpoint 会报 UnpicklingError。
   服务里显式放行 `XttsArgs / XttsAudioConfig / BaseDatasetConfig`，
   并把 `torch.load` 包一层强制 `weights_only=False`（仅对这个可信来源）。

2. **torchaudio 要 FFmpeg 的 DLL**
   torchaudio 2.11 用 torchcodec 解码，而 Windows 上常常没有 FFmpeg DLL，
   一读 wav 就抛 `Could not load libtorchcodec`。装 FFmpeg 太重，
   所以把 `torchaudio.load` 换成 soundfile（走 libsndfile）。

3. **`inference_stream` 用不了**
   Coqui 0.22 的流式生成与 transformers 4.45 不兼容：
   `_prepare_attention_mask_for_generation` 里拿 int 当 tensor 用，抛
   `AttributeError: 'int' object has no attribute 'device'`。
   **所以流式接口改成「按句合成 + 按 20ms 分块推送」**——数据格式与真流式
   完全一致（int16 PCM 24kHz），客户端无感，代价是每句多等一两秒。

4. **模型下载要走镜像**
   本机代理到 huggingface.co 会 502，`scripts/fetch_voice_clone_model.py`
   会自动改走 `hf-mirror.com`。

## 五、手动启动

```bash
# 下载模型（约 1.9GB，只跑一次）
python scripts/fetch_voice_clone_model.py

# 启动服务（默认 50000 端口，cuda；显存不够可加 --device cpu）
python scripts/voice_clone_server.py --port 50000
```

模型放在 `data/models/xtts_v2/`，日志在 `logs/voice_clone.log`。
