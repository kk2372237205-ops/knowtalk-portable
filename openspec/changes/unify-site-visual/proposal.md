# 统一全站视觉与页面归属

## Why

首页与工作台已经是一套纸面语言（米白底、墨色字、蓝墨水强调、宋体展示字），
但 `avatar.html`、`knowledge-base.html`、`settings.html`、`admin.html` 四个页面仍是各自的内联样式：
深蓝顶栏 `#172033`、蓝紫渐变背景、圆角玻璃卡片、Inter 字体。同一个产品里两套视觉，跳页像换了个软件。

另外「管理后台」以独立页面存在于一级导航，而它本质上是接口与参数的一部分配置，
使用者要在两个入口之间来回跳。

## What Changes

- 新增 `web/shell.css`：全站外壳样式（统一顶栏、页面容器、纸面控件皮肤），供四个工具页复用。
- 四个工具页的顶栏 DOM 统一为同一结构：品牌、四项导览（工作台 / 数字人 / 知识库 / 接口与参数）、右侧用户位。
- 工具页的底色、字体、按钮、表单、卡片、表格、标签改为纸面语言，去掉深蓝顶栏与蓝紫渐变。
- 管理后台并入 `settings.html`，作为「接口与参数」页里的第二个分段；一级导航不再出现「管理后台」。
- 静态样式与脚本引用加版本号，避免浏览器缓存旧 CSS 造成新结构与旧样式错配。

## Impact

- 受影响页面：`web/index.html`（顶栏视觉对齐、资源版本号）、`web/workbench.html`（资源版本号）、
  `web/avatar.html`、`web/knowledge-base.html`、`web/settings.html`、`web/admin.html`。
- 新增文件：`web/shell.css`。
- 不改任何后端接口、不改任何表单元素 id、不改任何页面脚本行为。
- 不做：登录体系、画布工作流（另立变更）。
