# 增加课堂录制

## 为什么

展示页（`/knowtalk-chat.html`）现在是纯实时播放：学生错过一场就得等重播，教师也没法把一节课留档。
数字人画面就在左侧，把「录制」放进去最顺手，但只录人像不录课件，回看时不知道老师在讲哪一页。

## 做什么

在展示页数字人画面右下角加一个录制按钮：

- 录制时把人像与当前幻灯片合成到一张 16:9 画布，叠加当前字幕，混入 TTS 声音，导出一个 `.webm`。
- 录制中显示红点与计时，停止后浏览器直接下载，文件名带课程名与时间戳。
- 全程在浏览器内完成，不新增服务端接口、不新增依赖、不落服务端磁盘。

## 不做什么

- 不做云端存储、不做转码、不做剪辑。
- 不做无人值守的自动录制（开始与结束都由使用者点）。
- 不在工作台侧录屏（工作台没有可录的合成画面）。

## 影响

- 新增 `web/recorder.js`、`web/display.css`；改 `web/knowtalk-chat.html`。
- 展示页自此带 `body.site` 皮肤（与本次样式统一同批落地）。
