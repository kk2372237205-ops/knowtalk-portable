# 动作制作（MiniMax H3 图生视频）

## 为什么

「动作」现在是纯素材导入：`data/avatars/{id}/gestures/{gid}/` 里的三件套要么手工做，
要么沿用已下线的 Seedance 通路（2026-10-24 随功能一起删除），管理页只能预览、改名、删除。
讲师想加一个「掌心向上展示」，唯一办法是自己在外部平台出片、再跑一遍 `genavatar`。

现在 MiniMax 的 **H3** 模型开放了图生视频（`POST /v2/video_generation`，`content[]` 里用
`role: first_frame` 传首帧），正好对上既有链路缺的那一环：

```
形象首帧(full_imgs/00000000.png) + 提示词 --H3--> 5 秒视频 --generate_avatar--> 三件套
```

## 做什么

- 数字人管理的「动作」面板里加「制作新动作」：选预设（8 套，名称 + 中文提示词，可改）、
  填名称、选时长/分辨率 → 一键生成。进度可见（排队 / 出片 / 下载 / 切帧 / 完成 / 失败）。
- 后端把 H3 任务与素材生成串成一个作业：建任务 → 轮询 → 下载 mp4 → `generate_avatar`
  → 归一化到该形象默认素材尺寸 → 写 `gesture.json`（label = 动作名）。
- 密钥与模型参数进设置页（`minimax.*`），不进源码。
- 生成完的动作立刻出现在动作列表与画布的手势节点里，不需要重启。

## 不做什么

- 不做视频编辑、不做参考图/参考视频那几种 H3 模式，只用首帧图生视频。
- 不做多人并发生成：同一形象同时只允许一个作业。
- 不改 `genavatar` 的算法与 `load_gesture` 的加载逻辑。

## 影响

- 新增依赖：`requests`（已在环境里）。
- 生成一次 5 秒 768P 大约 2–4 分钟（H3 出片 ~2 分钟 + 切帧 ~1 分钟），按次计费。
- 素材目录结构与既有手势完全一致，渲染层无需改动。
