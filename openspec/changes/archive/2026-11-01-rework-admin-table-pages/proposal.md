# 后台三张表重做：菜单加配置答案 / 问答记录加维度 / 知识库改两级

## Why

运营照着后台表格排的三张截图提了同一类问题：**表格里没有判断"这次回答到底从哪来"
需要的列**，于是现场答非所问时查不出原因。

1. **菜单配不出"固定话术"。** 菜单项只有「名称 / 配置问题 / 跳转链接」，想锁定一句
   标准答复（例如薪资新政的统一口径）只能靠知识库里那篇文档恰好答对。知识库一改，
   话术就变了；而知识库检索还可能命中别的内容。同样，讲解某个展品时要同时把画面
   切到对应素材，原来也没有地方配。

2. **问答记录筛不出"哪个库/哪台舱"。** 记录里只有时间、是否匹配、来源、问答文本。
   想看"某台舱今天命中率如何"或"某个知识库被问了多少次"，只能把 CSV 导出来自己透视——
   而这些维度**只有提问那一刻才拿得到**，事后靠答案文本反推不出来（同一个答案可能
   来自菜单固定答复，也可能来自知识库检索）。另外记录里混进调试时随口问的一句时，
   只能整表清空，没人敢点。

3. **知识库页一页铺到底。** 原来是"每个课程一大栏、栏里直接铺文件"：课程一多要滚
   很久，而"看看某个库里有什么"得先在一堆栏里找到它。

## What Changes

**菜单库（`desktop_app.py` MenuPage + `utils/kiosk_store.py` + `server/kiosk_routes.py`）**

- 菜单项新增 `answer`（配置答案）与 `material`（显示素材）两个真实字段，落 JSON，
  `update_menu` 白名单同步放行（留空即清除）。
- 命中后的作答顺序固定为：**配置答案 → 预置问题查知识库 → 菜单标题**。
  配了答案就 MUST NOT 再查知识库；配了素材就在播报前切画面。
- 界面改成后台表格：勾选 + 菜单排序 / 菜单名称 / 配置问题 / 配置答案 / 显示素材 /
  状态 / 操作（编辑 | 删除）+ 底部分页；工具栏「新增菜单 / 上移 / 下移 / 删除 / 搜索」。

**问答记录（`desktop_app.py` QaLogPage + `utils/kiosk_store.py` + `server/kiosk_routes.py`）**

- `append_qa` 增加 `source_name`（菜单标题 / 唤醒词）、`course`、`material`、`device`
  （默认主机名，可用 `KIOSK_DEVICE_NAME` 覆盖）四个维度，随记录一起落盘。
- `query_qa` 支持按这四个维度过滤；导出 CSV 增加对应列。
- 新增 `GET /api/kiosk/qa_log/facets`：下拉候选值按**全量记录**去重（只扫当页的话，
  第一页之后的取值永远选不到，用户会以为某个库从来没命中过）。
- 新增 `DELETE /api/kiosk/qa_log/{id}` 单条删除。
- 界面改成：回复类型 / 问题库 / 知识库 / 设备 四个下拉 + 查询，九列表格
  （问题、回复内容、是否匹配、显示素材、回复类型、问题库、知识库、设备名称、操作）+ 分页。

**知识库管理（`desktop_app.py` KnowledgePage）**

- 拆成两级：列表页是课程卡片网格（名称 + 文档数 + 索引状态），点卡片进详情页，
  详情页才有文档表格与「上传文档 / 重建索引 / 重命名 / 删除知识库」。
- 文档列表复用新的 `DataTable`，操作列为 预览 | 下载 | 重建 | 删除。
- 导航标签由「课程知识库」改名为「知识库管理」。

**通用表格组件（`desktop_app.py` DataTable）**

- 新增可复用的后台表格：勾选列（表头点击整页全选）、分页条、纯文本操作列按点击
  横坐标判定命中项。
- 列宽自适应：总宽超出可视宽度时按各列富余空间等比回收（Treeview 只在有富余时拉伸，
  超出时**不会收缩**，右侧几列会被推出可视区），底线是保证表头完整显示；
  压到底仍放不下才出横向滚动条。
- 分页条先于表格 pack：空间不足时 pack 先满足先装的控件，装晚了会被挤成 0 高。

## Out of Scope

- `kiosk.device_name` 暂不做界面入口，设备名仍取主机名 / `KIOSK_DEVICE_NAME`。
- 知识库后端接口（`/rag/admin/*`）不改，只改桌面端的浏览结构。
