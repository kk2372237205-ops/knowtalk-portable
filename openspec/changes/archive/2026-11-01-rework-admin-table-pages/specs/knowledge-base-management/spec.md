# 知识库管理（桌面端两级浏览）

## ADDED Requirements

### Requirement: 知识库管理页必须分两级浏览

桌面端知识库管理页 MUST 先展示课程卡片网格（每张卡至少显示课程名称、文档数与索引状态），
点击卡片 MUST 进入该课程的详情页；详情页 MUST 提供返回入口，并 MUST 只展示该课程的
文档。课程被删除或已不在列表中时，详情页 MUST 退回卡片网格，MUST NOT 停在空白页。

#### Scenario: 列表只回答"有哪些库"

- **WHEN** 进入知识库管理页
- **THEN** MUST 展示每个课程的一张卡片
- **AND** MUST NOT 在这一层直接铺开各课程的文档行

#### Scenario: 进入详情

- **WHEN** 点击某张课程卡片
- **THEN** MUST 展示该课程的文档列表
- **AND** MUST 提供返回卡片网格的入口

#### Scenario: 课程已被删除

- **WHEN** 停留在某课程详情页而该课程已从列表中消失
- **THEN** MUST 退回卡片网格

### Requirement: 文档列表必须支持预览、上传与删除

课程详情页 MUST 提供「上传文档」入口，并 MUST 为每个文档提供预览、下载、重建索引与
删除操作。文档为空时 MUST 给出明确的空状态提示，MUST NOT 显示空白表格。

#### Scenario: 空知识库

- **WHEN** 进入一个还没有文档的知识库
- **THEN** MUST 显示"还没有文档"之类的提示与上传入口

#### Scenario: 删除单个文档

- **WHEN** 对某个文档执行删除并确认
- **THEN** 该文档 MUST 从列表消失
- **AND** 同课程其它文档 MUST 保留
