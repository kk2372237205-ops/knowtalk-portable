# Proposal

## Why

首页长期停留在「Bootstrap 落地页」形态：渐变按钮、彩色图标块、勾选清单、三色点的假浏览器窗口、悬浮题卡。这些装饰与产品本身的技术密度不匹配，也让页面读起来像一份通用模板——不说明「讲稿就是指令」这个唯一的核心。

同时首页缺少能让人**看到**提问逻辑的东西：提问模式是产品最独特的能力（讲到第 N 页自己停下、静音、冻住幻灯片），但旧首页只有一句「按页码触发提问」，读者无法理解它到底怎么发生。

## What Changes

- **首页营销层整体换版**：改为纸面单栏排版（栏宽 680px，全页共享一条左边线），用宋体做展示字、系统黑体做正文，去掉全部装饰（eyebrow 小标签、圆形编号、彩色图标块、勾选清单、悬浮卡片、假浏览器三色点）。配色沿用现有的纸色 / 墨色 / 蓝墨水 / 黑板深灰 / 粉笔黄。
- **新增可交互的讲课演示面板**：左侧是播放页（页码、幻灯片标题、念稿与光标），右侧是六个控件。拖动「讲稿位置」，拖到第 3 页会停下、标为等人作答并显示题卡，拖走就接着讲——把「按页码触发提问」这件事变成可动手看的。
- **能力段改为四个「零件」**：形象与声音 / 课件与讲稿 / 课堂互动 / 知识库问答，每段配一块真实界面片段（形象参数、讲稿原文、判定条、问答与出处），深浅交替。
- **三步改为一张流程单**：三段（建形象 / 备课件 / 开讲）各列三行带时长的事项，底部一行合计。
- **新增常见问题段**：十二问连续阅读，不做折叠。
- **控制台一个不删**：所有表单 id、按钮、脚本引用、锚点全部保留，仅套用新的页面底色与卡片皮肤；`#capabilities`、`#workflow`、`#console` 三个锚点继续有效。
- **导航改为与正文同栏的静默横条**：不再是深色 sticky 通栏；`设置` 入口、连接状态徽标、会话号、「数字人说话中」提示全部保留。

## Capabilities

### New Capabilities

- `home-page-visual`：首页的视觉语言、信息架构，以及它与既有控制台功能的兼容契约。

### Modified Capabilities

无。

## Impact

- **前端**：`web/index.html` 的样式与营销区 DOM 重写；新增 `web/home.css` 承载首页皮肤；`docs/design/assets/lecturer.webp` 复制到 `web/assets/`（形象示意的真实素材，非编造）。
- **不受影响**：`web/index.html` 内 2000 余行控制台脚本、`quiz-panel.js`、`gesture-tags.js`、所有 `/api/*` 调用、`/avatar.html`、`/knowledge-base.html`、`/settings.html`、`/admin.html` 的链接与行为。
- **规格**：`frontend-asset-delivery` 的既有约束继续成立——新增的 `home.css` 与图片都是同源本地资产，不引入外部字体或 CDN。
