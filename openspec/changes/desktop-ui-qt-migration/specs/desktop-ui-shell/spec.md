## ADDED Requirements

### Requirement: 启动首帧不被阻塞

桌面界面必须在主窗口可见之前不发起任何同步网络请求；页面按需构造，未进入的页面不得在启动路径上创建。

#### Scenario: 主服务未就绪时启动

- **WHEN** 用户启动桌面端，而主服务还在加载模型
- **THEN** 主窗口在一秒内显示出导航与空内容区
- **AND** 界面线程不因等待任何接口而冻结
- **AND** 数据到位后由后台回调填充，期间不出现整片黑块

#### Scenario: 切换页面

- **WHEN** 用户点击导航里的某个页面
- **THEN** 该页面在此刻才被构造
- **AND** 已构造过的页面再次进入时复用实例，不重复构建

### Requirement: 主题热切换

切换外观主题必须在当前会话内即时生效，不需要重启界面进程。

#### Scenario: 换主题

- **WHEN** 用户在「外观」页选择另一套主题
- **THEN** 所有可见控件的底色、描边、文字色立即改变
- **AND** 当前所在页面与滚动位置保持不变

### Requirement: 数字人画面高效上屏

数字人视频帧必须以零拷贝方式交给绘制引擎，不得每帧生成整图缩放副本。

#### Scenario: 持续播放视频帧

- **WHEN** 视频帧以 25 帧以上的速率持续送入画面区
- **THEN** 每帧只有一次缩放绘制，不产生中间位图
- **AND** 画面按比例居中、四角圆角裁剪，不拉伸变形

### Requirement: 配置项控件外观一致

同一页面内的下拉、输入、分段、开关、数值框必须保持统一高度、圆角与描边，且不出现溢出到输入框外的原生子控件。

#### Scenario: 渲染时间类数值

- **WHEN** 页面出现「进入闲时 30 秒」这类数值输入
- **THEN** 输入的数值与单位完整显示在框内
- **AND** 不出现溢出边框的调节按钮残影
