# Spec Delta

## ADDED Requirements

### Requirement: 侧栏导航必须按使用模式分区

桌面端侧栏 MUST 提供「演讲模式」与「展览模式」两个互斥的使用模式，
并 MUST 在任一时刻只渲染当前模式对应的导航项。

默认模式 MUST 为演讲模式，默认落地页 MUST 为开播。

#### Scenario: 启动后处于演讲模式

- **WHEN** 用户登录后进入主工作台
- **THEN** 侧栏 MUST 显示「演讲模式」为选中态
- **AND** 导航项 MUST 为：讲稿、提问、课件、课程知识库、开播，
  以及通用区的形象与设置、管理后台、系统状态
- **AND** MUST NOT 出现唤醒与打断、菜单库、待机与迎宾、问答记录

#### Scenario: 切到展览模式

- **WHEN** 用户点击「展览模式」
- **THEN** 导航项 MUST 变为：唤醒与打断、菜单库、待机与迎宾、问答记录、开播，
  以及通用区三项
- **AND** MUST NOT 出现讲稿、提问、课件、课程知识库

### Requirement: 模式切换必须保留各模式上次所在页

切换模式时 MUST 记住离开该模式时所在的页面；切回该模式时 MUST 回到该页。
若该模式尚无访问记录，MUST 落到开播页。

#### Scenario: 从讲稿切到展览再切回

- **GIVEN** 用户当前在演讲模式的「讲稿」页
- **WHEN** 切换到展览模式，再切回演讲模式
- **THEN** 当前页 MUST 仍是「讲稿」
- **AND** 导航选中态 MUST 与当前页一致

### Requirement: 形象库、形象生成、语音与音频必须合并为单一入口

侧栏 MUST NOT 为「形象库」「形象生成」「语音与设置」分别提供导航项；
三者 MUST 收敛为一个「形象与设置」页，页内以分栏切换。

宿主页 MUST 只显示一次页面标题，子页 MUST NOT 重复渲染各自的大标题。

#### Scenario: 进入形象与设置

- **WHEN** 用户点击通用区的「形象与设置」
- **THEN** 页面 MUST 显示标题「形象与设置」与三个分栏：形象库 / 形象生成 / 语音与音频
- **AND** MUST 只显示一个页面主标题

#### Scenario: 顶栏设置快捷入口

- **WHEN** 用户点击顶栏的「设置」按钮
- **THEN** MUST 打开「形象与设置」页并停在「语音与音频」分栏

### Requirement: 导航在最小工作窗口内必须完整可见

在 1280×820 窗口、1.5 倍显示缩放下，侧栏 8 个导航项与 3 个分组标题
MUST 无需滚动即可完整显示。

#### Scenario: 标准窗口打开

- **WHEN** 以 1280×820 打开桌面端
- **THEN** 最后一个导航项与侧栏底部说明 MUST 均完整可见、无裁切
