# Spec Delta

## ADDED Requirements

### Requirement: 工作台必须是独立页面

工作台 MUST 位于 `/workbench.html`，作为可独立打开的页面存在。首页 MUST NOT 内嵌任何控制台表单控件；首页所有「进入工作台」入口（导航、首屏主按钮、流程段路径）MUST 跳转到该页，而不再指向页内锚点。

#### Scenario: 从首页进入工作台

- **WHEN** 使用者点击首页导航或首屏的「进入工作台」
- **THEN** 浏览器 MUST 导航到 `/workbench.html`
- **AND** 首页 MUST NOT 出现数字人连接、预设文本、提问模式三块表单中的任何一块

#### Scenario: 直接访问工作台地址

- **WHEN** 使用者直接在地址栏打开 `/workbench.html`
- **THEN** 页面 MUST 完整可用，不依赖从首页跳转带入的任何状态
- **AND** 地址中不带面板 hash 时 MUST 落在「开播」面板

### Requirement: 工作台必须采用三栏结构

桌面视口下，工作台 MUST 由三栏并排组成：左栏放面板切换与资源列表，中央放当前面板，右栏放「开播实况」。三栏 MUST 处于同一屏高度范围内，并各自独立滚动。

中央 MUST 在同一时刻只呈现一个面板，未选中的面板 MUST NOT 以折叠、隐藏在下方的形式继续占据文档流。中央底部 MUST 常驻一条操作条，承载「开始连接」「断开连接」、连接状态与会话号。

#### Scenario: 桌面视口下的结构

- **WHEN** 以 1280px 及以上宽度打开工作台
- **THEN** 左栏、中央与右栏 MUST 三栏并排显示，左右两栏 MUST 固定在视口内不随中央内容滚走
- **AND** 中央 MUST 只显示当前选中的那一个面板
- **AND** 中央底部 MUST 常驻显示连接按钮与连接状态

#### Scenario: 窄屏视口下降级

- **WHEN** 视口宽度小于 900px
- **THEN** 左栏 MUST 折叠为顶部的横排切换条，右栏 MUST 收起
- **AND** 切换项 MUST 仍可点击，并保持与桌面视口一致的面板切换行为
- **AND** 连接状态 MUST 仍可在顶部条与中央底部操作条看到

### Requirement: 左栏必须列出形象、课件与讲稿

左栏除面板切换项与页外链接外，MUST 再列出形象、课件、讲稿三组资源。三组 MUST 由页面上已有的下拉控件（`offerAvatar`、`offerPpt`、`presetSavedList`）渲染，MUST NOT 另起一套数据源。

点击形象或课件条目 MUST 同步对应控件的取值；点击讲稿条目 MUST 同步 `presetSavedList` 的取值，并触发与该控件自身 `onchange` 等价的载入、把中央切到讲稿面板。控件内容异步加载完成时，列表 MUST 自动重建。

#### Scenario: 左栏资源列表与中央面板同步

- **WHEN** 在左栏「形象」组点击某个形象
- **THEN** 中央开播面板的 `offerAvatar` MUST 取到同一个值
- **WHEN** 在左栏「讲稿」组点击某份讲稿
- **THEN** 讲稿编辑器 `presetText` MUST 载入该讲稿的正文，且中央 MUST 切到讲稿面板

### Requirement: 右栏必须汇总开播实况

右栏 MUST 汇总并实时显示七项：连接状态、会话号、播报状态、当前形象、当前音色、讲稿字数、提问组数。

每一项 MUST 取自中央控件的真实值，MUST NOT 显示编造或示例数字。讲稿字数 MUST 排除 `[SLIDE:n]`、`[GESTURE:x]` 一类标签后统计；提问组数 MUST 为问答对编辑区里实际存在的行数。

#### Scenario: 右栏实况随状态更新

- **WHEN** 数字人连接成功，或使用者修改了讲稿正文、增删了问答对
- **THEN** 右栏对应的「连接」「会话」「讲稿」「提问」MUST 在不刷新页面的前提下更新
- **AND** 右栏的每一项 MUST 与中央控件里的真实值一致

### Requirement: 点击导航必须切换右侧面板并保持状态

点击左栏切换项 MUST 立即把右侧内容替换为对应面板，并把当前面板写进地址栏 hash（`#start`、`#script`、`#quiz`）。刷新页面或使用浏览器前进后退 MUST 回到与地址栏一致的 panel，MUST NOT 因刷新回到默认面板。

#### Scenario: 点击未选中的导航项

- **WHEN** 当前在「开播」面板，使用者点击左栏「提问」
- **THEN** 右侧 MUST 变为提问面板，开播面板的控件 MUST NOT 可见
- **AND** 地址栏 hash MUST 变为 `#quiz`
- **AND** 被点击的切换项 MUST 呈现选中态，其余切换项 MUST 取消选中态

#### Scenario: 刷新与前进后退

- **WHEN** 地址栏为 `/workbench.html#script` 时刷新页面
- **THEN** 页面 MUST 直接呈现讲稿面板
- **IF** 使用者在切换过两个面板后按下浏览器后退
- **THEN** 页面 MUST 回到上一个面板，且选中态与右侧内容同步

### Requirement: 工作台必须承载控制台的全部功能契约

工作台 MUST 保留迁移前的全部对外可观察能力：所有表单控件与容器的元素 id、所有按钮的点击行为、`/quiz-panel.js` 与 `/gesture-tags.js` 的脚本引用，以及连接状态、会话号、「数字人说话中」等运行状态指示。迁移 MUST NOT 改变任何 `/api/*` 请求的路径、方法或载荷。

#### Scenario: 核对控件与脚本

- **WHEN** 对比迁移前后的控制台 DOM
- **THEN** 迁移前存在的每个控制台元素 id MUST 在工作台页存在且唯一
- **AND** 迁移前引用的两个脚本 MUST 仍被引用

#### Scenario: 跨面板的功能可用性

- **WHEN** 使用者在「开播」面板完成连接，再切到「讲稿」面板点击「播报预设文本」
- **THEN** 播报 MUST 使用开播面板中已建立的会话
- **AND** 切换面板 MUST NOT 断开连接、清空已保存的讲稿或丢失已填写的问答对

#### Scenario: 运行状态跨面板可见

- **WHEN** 数字人处于已连接或正在说话的状态
- **THEN** 该状态 MUST 在工作台顶部常驻可见，不随面板切换而消失

### Requirement: 左栏必须呈现导航层级

左栏 MUST 分成四个一级分组，每组 MUST 有一条不可点击的组标题：工作区（开播 / 讲稿 / 提问）、本次素材（形象 / 课件 / 讲稿）、流程（流程画布 / 当前流程）、站点（数字人 / 知识库 / 接口与参数）。

组标题 MUST NOT 可点击，MUST NOT 承载选中态。组内子项 MUST 相对组标题缩进，并由一条竖向导引线串起来，使父子关系一眼可辨。三个面板项 MUST 带两位序号（`01` `02` `03`）。

#### Scenario: 父子关系可辨

- **WHEN** 打开工作台
- **THEN** 左栏 MUST 出现四条组标题，点击标题 MUST NOT 触发任何跳转
- **AND** 每条标题下的子项 MUST 比标题缩进，并落在同一条竖线上

#### Scenario: 选中态只落在叶子项

- **WHEN** 当前在「开播」面板
- **THEN** 「开播」MUST 呈选中态并露出序号
- **AND** 「工作区」这条组标题 MUST NOT 呈选中态

#### Scenario: 窄屏仍分层

- **WHEN** 视口宽度小于 900px
- **THEN** 左栏 MUST 折成横排，组标题 MUST 隐藏
- **AND** 各可见分组之间 MUST 留有分隔，MUST NOT 连成一串无分组的链接
- **AND** 「本次素材」的条目在各面板下拉里仍可选，MUST NOT 因此丢掉选素材的能力

### Requirement: 工作台视觉必须与首页一致

工作台 MUST 复用首页的视觉令牌：纸色页面底色（`#fbf8f1`）、墨色正文（`#211f1a`）、蓝墨水强调（`#1f3b63`）、衬线展示字（Georgia 打头，中文回退 Songti SC / STSong / SimSun）。工作台 MUST NOT 引入首页之外的配色体系、外链字体或 CDN 资源。

#### Scenario: 比对页面皮肤

- **WHEN** 依次打开首页与工作台
- **THEN** 两者的页面底色、正文颜色与展示字字体族 MUST 相同
- **AND** 主按钮 MUST 沿用首页的蓝墨水实心样式（、无圆角、无投影）

#### Scenario: 工作台不得横向溢出

- **WHEN** 分别以 1440px、768px、390px 宽度渲染工作台
- **THEN** 每一档的文档滚动宽度 MUST 等于客户端宽度
- **AND** MUST NOT 存在右边界超出客户端的可见元素
