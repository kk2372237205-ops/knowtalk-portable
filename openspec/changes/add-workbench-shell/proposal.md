# Proposal

## Why

首页在 10-25 的换版里改成了纸面单栏的营销页，但控制台仍以「两块卡片纵向堆叠」的形式埋在首页底部。这带来两个问题：

1. **入口与内容是两件事，却挤在同一页。** 首页前 5 屏都在讲「它怎么讲课」，第 6 屏突然变成操作表单。读到操作区的人已经不想再看营销文案，可表单只有两张卡，看完要一路滚回去找导航。
2. **控制台没有空间长大。** 连接、讲稿、提问三件事共用一条竖直瀑布流，「讲稿」和「提问」并排成 `col-lg-7 / col-lg-5`，讲稿编辑框被压到 600px 宽；再接第四块（素材、记录）就只能继续往下堆。

工作台需要一层自己的骨架：左边常驻导航说明「这里有几件事」，右边一次只展开一件。

## What Changes

- **控制台从首页迁出，成为独立页面 `/workbench.html`**。首页不再内嵌任何表单；首屏按钮、导航「进入工作台」、流程段第三条路径全部改为跳转该页。
- **工作台采用左侧导航 + 右侧单面板结构**：左栏常驻三个切换项（开播 / 讲稿 / 提问），下方一组指路链接（形象生成 / 课程知识库 / 管理后台 / 参数设置）；右栏一次只显示一个面板。
- **切换状态写进地址栏**：`/workbench.html#start`、`#script`、`#quiz`，刷新与浏览器前进后退都能回到同一面板；不带 hash 时落在开播。
- **视觉沿用首页同一套令牌**：纸色底、墨色字、蓝墨水强调、衬线展示字、`hp-` 前缀的按钮与链接样式。控制台原有的彩色卡片与表单样式整体迁入 `web/workbench.css`，仅调整容器与导航皮肤。
- **窄屏降级**：视口小于 900px 时左栏折叠为顶部横排切换条，面板纵向排列。

## Capabilities

### New Capabilities

- `workbench-shell`：工作台的页面位置、导航结构、面板切换契约，以及它与控制台既有功能与首页视觉的一致性要求。

### Modified Capabilities

- `home-page-visual`：原「换版不得改变首页控制台的功能契约」要求 `#console` 锚点把读者滚到首页内嵌控制台，此条与新结构冲突，改写为「首页不得内嵌控制台，进入工作台必须跳转独立页」。

## Impact

- **前端**：新增 `web/workbench.html`、`web/workbench.css`；`web/index.html` 移除控制台 DOM 与其 338 行内联样式、移除主脚本（约 1400 行）迁至工作台页，仅保留营销区与演示面板脚本；页脚链接保留。
- **样式**：`web/home.css` 中 `body.home #console`、`.hp-console-*` 等仅服务控制台的规则随之删除。
- **不受影响**：所有 `/api/*` 调用与请求参数、`quiz-panel.js`、`gesture-tags.js`、`/avatar.html`、`/knowledge-base.html`、`/settings.html`、`/admin.html`、`/index-en.html` 的链接与内容。
- **兼容**：`/#console` 这类旧链接会落到首页（该锚点不再存在），首页导航已不再生成此类链接；`/workbench.html` 为新增路径，静态服务按文件直达，无需服务端路由改动。
