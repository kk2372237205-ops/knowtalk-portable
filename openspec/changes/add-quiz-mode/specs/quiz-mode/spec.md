# Spec Delta

## Purpose

在讲课过程中插入可配置或随机的提问点，让数字人停下讲课与幻灯片切换、抛出问题、接收文字或语音作答、由 LLM 判定并给出反馈后继续讲课；未启用时完全保持原有的连续讲授行为。

## ADDED Requirements

### Requirement: 提问模式与普通模式并存

未启用提问模式的会话，其朗读时序、切页时机与接口返回 MUST 与启用前一致。提问模式 MUST 按会话启用，MUST NOT 影响同一进程内其它未启用的会话。

#### Scenario: 普通模式行为不变

- **WHEN** 某会话未启用提问模式，客户端照常提交讲稿
- **THEN** 该会话 MUST 连续朗读全部教学段
- **AND** MUST NOT 产生提问、等待作答或判分行为

#### Scenario: 同进程内两种模式互不干扰

- **WHEN** 会话 A 已启用提问模式并正在等待作答，会话 B 未启用
- **THEN** 会话 B 的讲课 MUST 正常推进
- **AND** MUST NOT 被会话 A 的等待阻塞

### Requirement: 提问式讲课由服务端编排并按会话隔离

一次提问式讲课 MUST 按“教学段 → 提问点 → 等待作答 → 判分 → 反馈 → 下一教学段”的顺序由服务端推进，进度 MUST 按会话独立保存，MUST NOT 存放在全局单例中。

#### Scenario: 按序推进

- **WHEN** 一次提问式讲课启动并含有提问点
- **THEN** 服务端 MUST 先朗读该提问点之前的教学段
- **AND** 到达提问点后 MUST 进入等待作答状态，直到收到作答或放弃指令

#### Scenario: 会话之间进度独立

- **WHEN** 两个会话各自启动一次提问式讲课
- **THEN** 任意一个会话的进度变化 MUST NOT 改变另一个会话的当前教学段或提问点

### Requirement: 提问点由候选范围与数量确定

发起一次提问式讲课的请求 MUST 给出候选范围与提问数量；提问点 MUST 从候选范围内选取，MUST NOT 落在候选范围之外。请求未给出数量时 MUST 使用默认值。

#### Scenario: 按给定数量选取

- **WHEN** 请求给出候选范围与数量 3
- **THEN** 本次讲课 MUST 恰好产生 3 个提问点
- **AND** 全部提问点 MUST 位于候选范围内

#### Scenario: 候选范围不足以容纳所需数量

- **WHEN** 候选范围内的可选位置少于请求的提问数量
- **THEN** 服务 MUST 以业务错误拒绝该请求并说明可选数量
- **AND** MUST NOT 启动一次提问点数量不足的讲课

### Requirement: 提问点的选取方式可指定

请求 MUST 支持三种选取方式：随机抽取、按固定间隔、按显式给出的位置列表。未指定时 MUST 采用随机抽取。

#### Scenario: 按固定间隔选取

- **WHEN** 请求指定按固定间隔选取且间隔为 2
- **THEN** 提问点 MUST 落在第 2、4、6…… 个候选位置上

#### Scenario: 按显式位置选取

- **WHEN** 请求显式给出位置列表
- **THEN** 提问点 MUST 恰好为列表中的位置，MUST NOT 额外插入或删减

#### Scenario: 显式位置超出候选范围

- **WHEN** 显式位置列表中存在落在候选范围外的位置
- **THEN** 服务 MUST 以业务错误拒绝该请求

### Requirement: 随机选取必须可复现

采用随机抽取时，请求 MAY 给出随机种子。给定相同的候选范围、数量与种子时，MUST 得到完全相同的提问点集合。

#### Scenario: 同种子结果一致

- **WHEN** 用相同的候选范围、数量与种子发起两次讲课
- **THEN** 两次得到的提问点集合 MUST 完全相同

#### Scenario: 未给出种子时仍需可用

- **WHEN** 请求未给出随机种子
- **THEN** 服务 MUST 正常选取提问点，MUST NOT 因缺少种子而失败

### Requirement: 提问点可限定在指定幻灯片范围内

请求 MUST 支持限定提问点的幻灯片范围；给定时，提问点 MUST 只落在该范围内的幻灯片对应的讲稿段落上。

#### Scenario: 限定范围生效

- **WHEN** 请求把候选范围限定为幻灯片 3 至 5
- **THEN** 全部提问点 MUST 落在幻灯片 3 至 5 对应的段落上
- **AND** MUST NOT 在其它幻灯片上提问

### Requirement: 到达提问点时讲课与幻灯片切换同时停止

到达提问点时，服务 MUST NOT 继续发送后续教学段。正在朗读的段落 MAY 播完，但 MUST NOT 开始朗读下一段，且该会话的当前幻灯片 MUST 保持在停止时的取值。

#### Scenario: 讲课停住

- **WHEN** 一次讲课推进到某个提问点
- **THEN** 该会话 MUST NOT 自动开始朗读下一段
- **AND** 直到收到作答或放弃指令前 MUST 保持停止

#### Scenario: 幻灯片停住

- **WHEN** 讲课在提问点停住
- **THEN** 该会话的当前幻灯片 MUST 保持为停止时刻的取值
- **AND** MUST NOT 因后台推进而切换到后续段落所属的幻灯片

### Requirement: 抛出问题时题目必须被朗读且对作答方可见

到达提问点时，服务 MUST 把该题的题干交给该会话朗读，并 MUST 使作答方能够取得题干原文与题目标识。题干 MUST 按提问模式启用时选定的语言或原文呈现，MUST NOT 被朗读成标签或标记符号。

#### Scenario: 题目被朗读

- **WHEN** 讲课推进到某个提问点
- **THEN** 该会话 MUST 开始朗读该题的题干
- **AND** 朗读内容 MUST NOT 包含任何内部标记

#### Scenario: 作答方可取得题干

- **WHEN** 讲课处于等待作答状态，客户端查询提问状态
- **THEN** 响应 MUST 给出题目标识与题干原文
- **AND** MUST 给出该题所属的幻灯片编号

### Requirement: 状态查询接口给出题目与进度

服务 MUST 提供一个按会话查询提问状态的接口，返回当前阶段、当前题目、已完成的提问数与总提问数。该接口 MUST 在不处于提问模式时也返回成功响应并标明当前不处于提问模式。

#### Scenario: 等待作答时查询

- **WHEN** 会话处于等待作答状态时查询
- **THEN** 响应 MUST 标明当前阶段为等待作答
- **AND** MUST 给出题目标识、题干与已完成／总数

#### Scenario: 未启用提问模式时查询

- **WHEN** 对一个未启用提问模式的会话查询
- **THEN** 响应 MUST 为成功响应，并标明当前不处于提问模式

### Requirement: 文字作答接口

服务 MUST 提供文字作答接口，接收会话标识与作答文本。空文本或仅含空白的作答 MUST 被拒绝。受理后服务 MUST 停止等待作答状态并进入判分。

#### Scenario: 提交文字作答

- **WHEN** 在等待作答状态提交非空作答文本
- **THEN** 该会话 MUST 离开等待作答状态
- **AND** MUST 进入判分流程

#### Scenario: 提交空白作答

- **WHEN** 提交的作答文本为空或仅含空白
- **THEN** 服务 MUST 返回业务错误
- **AND** 该会话 MUST 仍停留在等待作答状态

### Requirement: 语音作答经转写后走同一条判分路径

服务 MUST 提供语音作答接口，接收音频并转写为文本；转写结果 MUST 与文字作答走完全相同的判分、反馈与继续讲课路径。转写失败时 MUST 返回业务错误并保留等待作答状态。

#### Scenario: 语音作答成功

- **WHEN** 在等待作答状态提交一段可识别的语音
- **THEN** 服务 MUST 以转写出的文本作为作答
- **AND** 后续判分与反馈行为 MUST 与等价的文字作答一致

#### Scenario: 转写失败

- **WHEN** 提交的音频无法识别或格式不受支持
- **THEN** 服务 MUST 返回业务错误
- **AND** 该会话 MUST 仍停留在等待作答状态，允许重新作答

### Requirement: 判分依据参考答案与评判要点

判分 MUST 使用该题的参考答案与评判要点，由对话 LLM 判定作答是否覆盖要点。判分结果 MUST 给出结论（正确／部分正确／未覆盖）与一段面向学员的反馈语。

#### Scenario: 作答覆盖要点

- **WHEN** 提交的作答覆盖了该题的评判要点
- **THEN** 判分结论 MUST 为正确
- **AND** MUST 产出一段可用于朗读的反馈语

#### Scenario: 作答偏离要点

- **WHEN** 提交的作答未覆盖任何评判要点
- **THEN** 判分结论 MUST 为未覆盖
- **AND** 反馈语 MUST 指出题目考察的关键点

### Requirement: 判分反馈由数字人朗读后继续讲课

判分完成后，服务 MUST 把反馈语交给该会话朗读，并在反馈朗读结束后按配置继续推进到下一教学段或下一提问点。

#### Scenario: 反馈后继续

- **WHEN** 判分完成且该会话已朗读反馈语
- **THEN** 服务 MUST 继续推进该次讲课
- **AND** MUST NOT 重复朗读已讲过的教学段

#### Scenario: 已到达最后一个提问点

- **WHEN** 判分完成且不存在后续提问点
- **THEN** 服务 MUST 朗读剩余的全部教学段直到讲课结束
- **AND** MUST 把该会话标记为讲课已完成

### Requirement: 判分不可用时必须降级且不得卡住课堂

当对话 LLM 不可用或判分失败时，服务 MUST 记录该次作答但 MUST NOT 阻塞流程，且 MUST 在结果中明确标明该次判分未完成。课堂 MUST 能够继续推进。

#### Scenario: LLM 不可用时降级

- **WHEN** 判分时对话 LLM 不可用
- **THEN** 服务 MUST 记录作答原文并标明判分未完成
- **AND** MUST 继续推进讲课，MUST NOT 停留在等待作答状态

#### Scenario: 判分结果中的降级标记

- **WHEN** 一次判分以降级结束
- **THEN** 状态查询与问答记录中 MUST 能区分该次判分未完成

### Requirement: 等待作答超时可放弃

等待作答 MUST 支持超时或显式的放弃／跳过指令；触发后服务 MUST 记录该题未作答并继续推进讲课。超时时长 MUST 可配置。

#### Scenario: 显式跳过

- **WHEN** 在等待作答状态提交跳过指令
- **THEN** 该题 MUST 被记录为未作答
- **AND** 讲课 MUST 继续推进

#### Scenario: 超时放弃

- **WHEN** 等待作答超过配置的时长且未收到任何作答
- **THEN** 服务 MUST 记为未作答并继续推进
- **AND** MUST NOT 永久停留在等待作答状态

### Requirement: 题库条目结构

题库中的每一题 MUST 至少包含题目标识、题干、参考答案与评判要点，MAY 包含所属幻灯片编号、难度与来源标记。题库 MUST 持久化在服务端，并 MUST 位于版本库忽略范围内。

#### Scenario: 条目字段完整

- **WHEN** 读取题库中的条目
- **THEN** 该条目 MUST 含有题目标识、题干、参考答案与评判要点
- **AND** MUST 标明其来源是人工录入还是自动生成

#### Scenario: 题库文件损坏

- **WHEN** 题库文件无法解析
- **THEN** 服务 MUST 以空题库启动并保留原文件
- **AND** MUST 记录可定位的错误

### Requirement: 题库的增删改查接口

服务 MUST 提供题库的列举、新增、修改与删除接口。删除不存在的题目 MUST 返回业务错误。新增时缺少题干或参考答案 MUST 被拒绝。

#### Scenario: 新增并列举

- **WHEN** 提交一条含题干与参考答案的题目后列举题库
- **THEN** 该题目 MUST 出现在列举结果中

#### Scenario: 删除不存在的题目

- **WHEN** 删除一个不存在的题目标识
- **THEN** 服务 MUST 返回业务错误
- **AND** MUST NOT 影响其它题目

### Requirement: 依据幻灯片与知识库自动出题

服务 MUST 支持依据指定幻灯片的文字内容出题；启用知识库时 MAY 一并检索相关内容作为出题依据。出题结果 MUST 包含题干、参考答案与评判要点，且 MUST 在落库后才可用于讲课。

#### Scenario: 按幻灯片出题

- **WHEN** 请求依据某张幻灯片出题
- **THEN** 服务 MUST 返回题目，且题干 MUST 与该幻灯片内容相关

#### Scenario: 出题结果落库

- **WHEN** 出题成功但未落库
- **THEN** 该题 MUST NOT 出现在题库列举结果中
- **AND** MUST NOT 被提问式讲课选用

### Requirement: 一次讲课中同一题目不得重复出现

一次提问式讲课中，同一个题目 MUST 至多被提问一次。题库中可用题目少于提问点数量时，服务 MUST 以业务错误拒绝启动并说明可用数量。

#### Scenario: 题目不重复

- **WHEN** 一次讲课包含 3 个提问点
- **THEN** 3 个提问点对应的题目标识 MUST 互不相同

#### Scenario: 题目数量不足

- **WHEN** 题库中可用题目少于提问点数量
- **THEN** 服务 MUST 拒绝启动该次讲课并说明可用数量
- **AND** MUST NOT 以重复题目凑数

### Requirement: 问答记录可查询

服务 MUST 记录每次提问的题目、作答原文、判分结论与是否降级，并 MUST 提供按会话查询记录的接口。记录 MUST 持久化在版本库忽略范围内。

#### Scenario: 记录包含判分与降级标记

- **WHEN** 一次讲课完成后查询该会话的问答记录
- **THEN** 每条记录 MUST 含题目、作答原文与判分结论
- **AND** 降级结束的记录 MUST 带有未完成标记

#### Scenario: 未作答也被记录

- **WHEN** 某题被跳过或超时放弃
- **THEN** 该题 MUST 出现在记录中并标明未作答

### Requirement: 学员交互接口的作用范围限于单个会话

学员在课堂上使用的提问状态查询、文字作答、语音作答与跳过接口 MUST 只作用于调用方指定的会话，MUST NOT 提供跨会话的批量操作。

（原「不受访问口令拦截」的表述已随 2026-10 访问口令机制退役而失效：服务端不再存在口令校验层，因此该约束不再需要单独声明。）

#### Scenario: 接口作用范围受限

- **WHEN** 学员交互接口被调用
- **THEN** 其影响 MUST 限于请求中指定的会话

### Requirement: 可按幻灯片指定要问的题目

发起一次提问式讲课的请求 MUST 支持给出一张「幻灯片编号 → 题目标识」的绑定表。存在绑定的提问点 MUST 使用该绑定的题目，MUST NOT 被随机或固定间隔选取覆盖。

#### Scenario: 绑定生效

- **WHEN** 请求把幻灯片 3 绑定到某道题，且幻灯片 3 是本次的候选提问点
- **THEN** 该提问点 MUST 问所绑定的那道题
- **AND** MUST NOT 换成其它题目

#### Scenario: 绑定与选取方式并存

- **WHEN** 一次讲课既有绑定又有未绑定的提问点，且选取方式为随机
- **THEN** 已绑定的提问点 MUST 保持其绑定题目
- **AND** 未绑定的提问点 MUST 从未被占用的题目中按随机选取

### Requirement: 绑定表必须校验且冲突必须被指明

绑定表引用不存在的题目标识、绑定到不属于本次候选提问点的幻灯片、或把同一题目标识绑定到多个幻灯片时，服务 MUST 以业务错误拒绝启动该次讲课，并 MUST 指明发生冲突的幻灯片编号或题目标识。

#### Scenario: 引用不存在的题目

- **WHEN** 绑定表引用了题库中不存在的题目标识
- **THEN** 服务 MUST 返回业务错误并指明该题目标识
- **AND** MUST NOT 启动该次讲课

#### Scenario: 绑定到候选范围之外的幻灯片

- **WHEN** 绑定表给出的幻灯片编号不是本次讲课的候选提问点
- **THEN** 服务 MUST 返回业务错误并指明该幻灯片编号

#### Scenario: 同一题被绑定到多个幻灯片

- **WHEN** 绑定表把同一个题目标识绑定给两个幻灯片
- **THEN** 服务 MUST 返回业务错误
- **AND** MUST NOT 以重复题目启动该次讲课

### Requirement: 题目自身的所属幻灯片不参与绑定校验

题目的所属幻灯片仅用于筛选与自动出题，MUST NOT 被用作绑定校验条件；题目 MAY 被绑定到与其所属幻灯片不同的幻灯片上。

#### Scenario: 跨页绑定复习题

- **WHEN** 把一道所属幻灯片为 1 的题绑定到幻灯片 5 的提问点
- **THEN** 服务 MUST 接受该绑定并按绑定执行
- **AND** MUST NOT 因所属幻灯片不匹配而拒绝

### Requirement: 发起时可内联给出问答对

发起一次提问式讲课的请求 MUST 支持随请求一并给出问答对（题干与参考答案必填，评判要点 MAY 省略）。给出内联问答对时，这些问答对 MUST 直接被本次讲课使用，MUST NOT 要求它们先写入题库，MUST NOT 依赖幻灯片文字或自动出题。题库为空时，内联讲课 MUST 仍能启动。

#### Scenario: 题库为空也能启动内联讲课

- **WHEN** 题库中没有任何题目，请求内联给出 3 个问答对
- **THEN** 服务 MUST 启动该次讲课，且这 3 个问题 MUST 分别被提问
- **AND** MUST NOT 因题库为空而拒绝

#### Scenario: 问答对缺少题干或参考答案

- **WHEN** 某个内联问答对缺少题干或参考答案
- **THEN** 服务 MUST 以业务错误拒绝启动该次讲课
- **AND** MUST 指明是第几个问答对

### Requirement: 内联问答对决定提问数量与顺序

给出内联问答对时，本次讲课的提问数量 MUST 等于问答对的数量，MUST NOT 受请求中提问数量字段影响。未指定幻灯片的内联问答对 MUST 按其在请求中给出的顺序依次分配给提问点。

#### Scenario: 数量由问答对决定

- **WHEN** 请求内联给出 2 个问答对，同时给出提问数量 5
- **THEN** 本次讲课 MUST 恰好产生 2 个提问点
- **AND** MUST NOT 因数量字段而多问

#### Scenario: 顺序被保持

- **WHEN** 请求内联给出问答对 A、B、C，且它们都未指定幻灯片
- **THEN** A MUST 先于 B 被提问
- **AND** B MUST 先于 C 被提问

### Requirement: 内联问答对可指定提问所在幻灯片

内联问答对 MAY 指定要问的幻灯片。指定时，该问答对 MUST 问在该幻灯片对应的提问点，且该题开始朗读时该会话的幻灯片 MUST 切换到该页。指定的幻灯片不是本次候选提问点、或两个问答对指定同一幻灯片时，服务 MUST 以业务错误拒绝启动并指明冲突项。

#### Scenario: 指定幻灯片生效

- **WHEN** 某内联问答对指定幻灯片 3，且幻灯片 3 是本次的候选提问点
- **THEN** 该提问点 MUST 问该问答对
- **AND** MUST NOT 被分配其它问答对

#### Scenario: 两个问答对指定同一幻灯片

- **WHEN** 两个内联问答对都指定幻灯片 2
- **THEN** 服务 MUST 以业务错误拒绝启动
- **AND** MUST 指明该幻灯片编号

#### Scenario: 指定到非候选幻灯片

- **WHEN** 某内联问答对指定了一个不是本次候选提问点的幻灯片
- **THEN** 服务 MUST 以业务错误拒绝启动
- **AND** MUST 指明该幻灯片编号

### Requirement: 无讲稿时可只提问

请求 MAY 省略讲稿。省略讲稿且给出内联问答对时，本次讲课 MUST 按问答对顺序逐题提问，MUST NOT 投喂任何教学段；每题判分后的反馈 MUST 照常朗读。完成最后一题的判分与反馈后，服务 MUST 结束该次讲课。

#### Scenario: 纯提问不朗读教学段

- **WHEN** 请求只给出内联问答对、未给出讲稿
- **THEN** 服务 MUST 依次抛出各题题干
- **AND** MUST NOT 投喂任何教学段

#### Scenario: 纯提问正常结束

- **WHEN** 最后一个内联问答对完成判分与反馈
- **THEN** 该会话 MUST 被标记为讲课已完成
- **AND** MUST NOT 停留在等待作答状态

### Requirement: 内联问答对与绑定表不得同时使用

请求同时给出内联问答对与「幻灯片编号 → 题目标识」绑定表时，服务 MUST 以业务错误拒绝启动，MUST NOT 自行猜测优先级。

#### Scenario: 二者同时给出被拒绝

- **WHEN** 请求既给出内联问答对又给出绑定表
- **THEN** 服务 MUST 返回业务错误
- **AND** MUST NOT 启动该次讲课
