# avatar-compositing Specification

## Purpose
定义人像抠像 alpha 素材的生成口径：肢体之间背景缝的识别判据，以及运行时把单帧人像合成到自定义背景上的约束。

## Requirements

### Requirement: 肢体之间的背景缝必须按形状 + 颜色联合判定

识别"肢体之间透出的背景缝"（臂身缝、腿侧缝、指缝）时 MUST 同时使用形状与颜色判据：
块内颜色到背景色的中位距离 MUST 在背景阈值之内（说明缝里确实是背景色）、
最大内切半径 MUST 不超过 9 px（说明够细）、外接矩形长宽比 MUST 不小于 3.0
（说明是顺着肢体延伸的窄长条）。MUST NOT 只用颜色判据——白衬衫与影棚白底在颜色上
无法区分，纯颜色判据必然在"清掉缝"和"不吃衣服"之间二选一。

#### Scenario: 细长背景缝

- **WHEN** 输入一个 23×171 的竖长条，整体为中性背景白
- **THEN** 该块 MUST 被判定为缝并清成透明

#### Scenario: 又宽又短的白色亮块

- **WHEN** 输入一个接近正方形、颜色同样是背景白的块（白衬衫补丁）
- **THEN** 该块 MUST NOT 被判定为缝
- **AND** 该区域的 alpha MUST 保持不透明

#### Scenario: 颜色不是背景色的细长块

- **WHEN** 输入一个细长但颜色明显偏离背景色的块（布料褶皱）
- **THEN** 该块 MUST NOT 被判定为缝

### Requirement: 缝隙掩膜必须在最终成品上复核

用于清除的缝隙掩膜 MUST 在形态学补全（闭运算、外扩）**之后**再整体复核一遍形状与
颜色判据。MUST NOT 只对候选种子做判定——小种子经 7×7 / 9×9 闭运算会膨胀成团块，
此时它已越过缝的边界啃到旁边的衣物上。

#### Scenario: 补全后长胖的块

- **WHEN** 一块真缝经闭运算后变成内切半径 10、长宽比接近 1 的团块
- **THEN** 该块 MUST 在复核阶段被剔除
- **AND** 衣物区域的 alpha MUST 保持不透明

### Requirement: 合成必须走「先去污染、再 alpha 混合」

把人像帧合成到背景上时 MUST 使用 `out = a·F + (1-a)·bg`，其中 F 是**去污染后的前景**
（实心人体颜色外推到半透明边缘）。MUST NOT 使用 `out = src + (1-a)·(bg - bg_src)`——
后者假设 alpha=0 处的源像素严格等于背景色，而棚拍素材在这一带普遍存在接触阴影、
打光反光与上下渐变，会原样保留 `src - bg_src` 的差，换背景后留下一个人形轮廓的残影。

#### Scenario: 人像旁边的投影

- **WHEN** 源帧背景区有一块比标准背景暗的接触阴影（alpha=0）
- **THEN** 该区域 MUST 严格等于新背景色
- **AND** MUST NOT 残留任何源素材的亮度

#### Scenario: 身体周围的反光

- **WHEN** 源帧背景区有一块比标准背景亮的打光反光（alpha=0）
- **THEN** 该区域 MUST 严格等于新背景色

### Requirement: 羽化出的半透明边缘必须混入前景色而非源背景色

alpha 处于过渡带的像素，其参与混合的颜色 MUST 取自邻近的实心人体
（alpha ≥ 250），MUST NOT 直接使用源帧该像素的颜色。抠像为吃掉白边所做的
腐蚀与羽化会把轮廓内侧的 alpha 压到 0.2~0.8，但那些像素本就是实心人体；
拿源帧颜色直接混合会往人体里掺进源背景色，且旧式子的结果会被截断成纯黑。

#### Scenario: 深色西装轮廓的半透明边缘

- **WHEN** 人体为深色、源背景为白，某边缘像素 alpha 约 0.5 且源帧该处仍为人体色
- **THEN** 合成结果 MUST 落在「人体色」与「新背景色」之间
- **AND** MUST NOT 被截断成比两者都暗的纯黑

### Requirement: 前景色外推只覆盖人体边缘，且必须在实时预算内

外推 MUST 只处理 alpha 高于下限（25）的环带——低于该值的是脚下接触阴影这类
本应留成背景的区域。MUST NOT 用全图距离变换求最近实心像素（实测 58.7 ms/帧）。
1080×538 的单帧合成（含 alpha 解码与外推）MUST 保持在 26 ms 以内。

外推 MUST 覆盖整条软边，而不是固定 2 圈：AI 抠像输出的过渡带有 3~5 px 宽，
只推 2 圈时外圈约 30% 的边缘像素（真实素材每帧 3000~4000 个）拿不到干净前景，
仍带着源背景的白，合成后在深色底上就是一圈白雾，手部动作（挥手的手掌指尖、
胸前的指缝）尤其明显。默认轮数 MUST 取 6，并在代码里记下实测依据。

#### Scenario: 带羽化边缘的真实素材

- **WHEN** 逐帧合成一个 107 帧的动作序列
- **THEN** 单帧耗时的中位数 MUST 低于 26 ms
- **AND** 测试用的羽化宽度 MUST 贴近真实素材（3~5 px）——用 2 px 窄斜坡的话
  外推循环会提前退出，轮数再大也测不出真实开销

#### Scenario: 宽软边的外圈不得残留源背景色

- **WHEN** 合成一条 5~6 px 宽的过渡带，其源帧像素为「人体色与背景色的混合」
- **THEN** 合成结果 MUST 落在 [人体色, 背景色] 区间内（过冲 < 3）
- **AND** 该断言 MUST 在外推轮数退回 2 时失败——否则这条用例只是在跑通，
  并没有锁住修复

#### Scenario: 环带为空时提前退出

- **WHEN** 某帧的软边本来就窄
- **THEN** 外推循环 MUST 在环带为空时立即退出，不为窄边缘白付代价

### Requirement: 序列式抠像引擎必须整段按序推理

带循环状态的抠像引擎（如 RVM，把上一帧的循环状态带进下一帧）MUST 按帧序**整段**
推理，状态在帧之间传递。MUST NOT 逐帧独立调用——那样会丢掉时序记忆，退化成
"每帧重新猜一遍"。素材生成循环 MUST 按帧源整段跑一次，再逐帧落盘。

#### Scenario: 一个 124 帧的动作序列

- **WHEN** 用序列引擎处理某个动作的连续帧
- **THEN** 这些帧 MUST 在同一次推理中按顺序处理
- **AND** 循环状态 MUST 从上一帧带到下一帧

### Requirement: alpha 的低值尾巴必须硬阈值归零

alpha 低于下限的像素 MUST 用**硬阈值**直接置 0，MUST NOT 用线性拉伸
（如 `(a - k) / (1 - k)`）。线性拉伸会在 0 附近留下 0.01 级的尾巴，这些像素
低于运行时的前景外推下限却仍非零——既没被外推洗干净、alpha 又不为 0，合成时
会掺进 `(1-a)` 份源背景色，深色底上是一圈白雾。
下限 MUST 高于外推下限（`EDGE_MIN=25/255≈0.098`），保证凡是还留着 alpha 的
像素都能被外推覆盖。

#### Scenario: 模型软边外沿那一圈

- **WHEN** 抠像模型在轮廓外沿输出 alpha 约 0.05~0.15 的软边
- **THEN** 低于下限的部分 MUST 归零
- **AND** 剩余非零像素 MUST 全部高于外推下限
- **AND** 合成后背景区残留 MUST 为 0

### Requirement: 接地阴影必须由该帧自己的 alpha 求接触带

抠像时脚下的接触阴影 alpha 低于外推下限，会被当作背景丢弃，人像贴到新背景上
脚下是一条齐刷刷的切口、有悬浮感。补接地阴影时 MUST 从**当前帧自己的 alpha**
求接触带：取实心像素（alpha ≥ 200）的最低行作为触底 y，在它上方一小段内求水平
跨度作为接触宽度，中心 x 取跨度的中点。MUST NOT 用一套固定的画面底部椭圆——
动作里有抬腿、侧身、重心转移，接触点会左右移动，固定椭圆会在人动起来时脱脚。

#### Scenario: 正常站姿

- **WHEN** 一帧 alpha 的实心区底部横跨 x∈[420, 660]、最低行 y=1010
- **THEN** 接触中心 MUST 落在 x≈540
- **AND** 接触宽度 MUST 约为 241

#### Scenario: 动作中重心移到左脚

- **WHEN** 同一形象另一帧的实心区底部整体左移
- **THEN** 阴影中心 MUST 跟着左移
- **AND** MUST NOT 沿用其它帧算出的位置

### Requirement: 接地阴影只作用于背景层，不得改变人体像素

阴影 MUST 以"遮挡环境光"的方式乘在背景上：`bg' = bg · (1 - s·strength·(1-shade))`，
再走原有的 `out = a·F + (1-a)·bg'`。MUST NOT 把阴影叠在合成之后的结果上——
那样等于给人像的鞋面和裤脚糊上一层灰，抠像辛苦保住的边缘又被涂回去。

#### Scenario: 人像躯干与头部区域

- **WHEN** 开启阴影后合成同一帧
- **THEN** alpha ≥ 250 的实心人体像素 MUST 与关闭阴影时逐像素一致

#### Scenario: 脚下的背景

- **WHEN** 开启阴影后合成同一帧
- **THEN** 接触带正下方的背景像素 MUST 比关闭阴影时更暗
- **AND** 阴影中心 MUST 是最暗处，向外单调变淡

### Requirement: 阴影不得就地修改缓存的背景图

背景图按尺寸缓存在 `_bg_cache` 里被所有帧共用，叠阴影时 MUST 先复制再改。
MUST NOT 就地写回缓存——那会让阴影一帧一帧累积，几秒内把脚下压成一块黑。

#### Scenario: 连续合成 100 帧

- **WHEN** 连续对同一尺寸的 100 帧做合成（缓存背景命中）
- **THEN** 第 100 帧脚下阴影的暗度 MUST 与第 1 帧一致
- **AND** 缓存中的背景图 MUST 保持未被叠过阴影的状态

### Requirement: 帧内没有可靠脚部时不得画阴影

alpha 全空（还没推上来的帧）或接触带像素太少（人像被画面下边缘裁掉、只剩一条边）
时 MUST 跳过阴影。MUST NOT 在这时退化成"画面底部居中来一片"——被裁掉的画面里
硬画一片椭圆，会在人像脚下凭空多出一团与姿态无关的暗斑。

#### Scenario: 空帧

- **WHEN** alpha 全为 0
- **THEN** 合成结果 MUST 严格等于背景图
- **AND** MUST NOT 出现任何阴影

### Requirement: 接地阴影必须在实时预算内

脚部求解与阴影图 MUST 按「帧源 + 帧号 + 尺寸 + 参数签名」缓存，热路径上只保留
一次小范围的乘法。1080×538 单帧合成（含外推与阴影）的中位耗时 MUST 保持在
26 ms 以内——阴影带来的增量 MUST 低于 3 ms。

#### Scenario: 连续合成一个动作序列

- **WHEN** 逐帧合成 107 帧
- **THEN** 单帧耗时中位数 MUST 低于 26 ms
- **AND** 阴影缓存的键 MUST 包含参数签名（改参数后旧缓存不得再命中）

### Requirement: 阴影配置必须与背景配置一样可热重载

阴影参数落 `data/settings/shadow.json`，检测方式沿用背景那套「修改时间 + 大小」戳。
`AvatarBackground` 的戳 MUST 同时包含两个配置文件，任一变化都触发重载。
MUST NOT 要求用户重连数字人才能看到参数变化。

#### Scenario: 界面里拖动强度滑块

- **WHEN** 写入 shadow.json 后合成下一帧
- **THEN** 该帧 MUST 使用新的强度值
- **AND** 旧的阴影缓存 MUST 全部作废

### Requirement: 阴影默认关闭时不得改变既有合成结果

`shadow.enabled` 为 false 时，合成 MUST 走原路径、结果与改动前逐像素一致。
MUST NOT 因为引入阴影而在关闭态下多一次复制或改变像素舍入。

#### Scenario: 关闭阴影

- **WHEN** 配置为 `{"enabled": false}` 并合成一帧
- **THEN** 输出 MUST 与不传任何阴影配置时逐像素相同
